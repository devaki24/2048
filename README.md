🎮 2048 Game — Classic Puzzle Game Implementation

This repository contains a clean and fully functional implementation of the 2048 puzzle game, built to enhance logical thinking, problem-solving skills, and programming ability. The objective of the game is simple—merge matching tiles by sliding them across a 4×4 grid and reach the 2048 tile or even higher!

Designed with simplicity and performance in mind, this project demonstrates core concepts such as game logic development, matrix manipulation, event handling, and interactive gameplay.

✨ Key Highlights

🔢 4×4 sliding board with smooth tile movements

➕ Automatic merging logic for matching values

🧠 Game state detection (Win / Game Over)

🎮 Keyboard control support for smooth play

📊 Real-time score calculation

🧼 Clean and readable source code
